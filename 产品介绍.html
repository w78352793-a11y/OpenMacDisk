OpenMacDisk

在 Windows 上浏览、提取与制作 macOS 磁盘镜像（.dmg）的轻量原生工具

当前版本 v1.4.3 · 便携版 · 免安装

产品定位

OpenMacDisk 是一款面向 Windows 平台的 macOS 磁盘镜像处理工具。它无需安装、单文件运行， 让用户在 Windows 资源管理器之外，直接查看 .dmg 镜像内部的目录与文件结构， 提取所需文件，并可将文件夹重新封装为标准 DMG。所有生成的镜像均保持与 macOS 原生格式一致， 可在 Mac 上正常挂载打开。

核心功能

镜像浏览
打开各类 DMG，树状展示卷内目录与文件，支持中文、俄文等 Unicode 文件名。
文件提取
将镜像内的任意文件/文件夹导出到 Windows 磁盘。
eXpand 展开
把压缩的只读 DMG 展开为未压缩、可直接编辑的镜像副本。
Compress 封装
把文件夹或镜像重新封装为只读 / 未压缩的 DMG。
多语言
内置简体中文 / 英文界面，可随时切换。
外观主题
亮色、暗色、透明玻璃、磨砂玻璃四种窗口风格自由切换。

格式兼容性

镜像封装分区方案文件系统支持方式
UDIF (.dmg)GPTAPFS只读浏览 / 提取
UDIF (.dmg)APM / 整盘卷HFS+ / HFSX可读写编辑
说明：HFS+/HFSX 卷支持向镜像内添加文件；APFS 卷当前为只读（浏览与提取）， 写入支持将在后续版本规划。所有解析均为对公开磁盘格式规范的独立实现。

技术亮点

  • 逐字节保真：展开 / 重封装产物与原生格式一致，Mac 可正常挂载，不破坏镜像结构。
  • 真正便携：单文件 EXE，配置与设置保存在程序同目录，可放入 U 盘带走、换机即用。
  • 原生体验：基于 Windows 原生 GUI 与系统图标，启动快、占用小（约 20 MB）。
  • 格式覆盖面广：GPT / APM 分区、HFS+、APFS 多类真实镜像均已验证可打开。

便携版使用说明

  • 将 OpenMacDisk 文件夹整体复制到任意位置（如桌面、U 盘）。
  • 双击 OpenMacDisk.exe 即可运行，无需安装、不写注册表。
  • 你的语言与外观设置会自动保存在该文件夹内的 config.json，随文件夹一起移动。
